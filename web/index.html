HOW TO READ THIS

A course-level early signal

For the selected course, the model compares assessment completion, scores and submission timing during the first 60 days with historical OULAD module patterns. It estimates the likelihood of passing that course; use the result to guide support—not as a guaranteed final result.

Select a registered course and run an assessment to receive a personalized recommendation.

OULAD · FIRST 60 DAYS

Predict a course outcome

Select one of your registered courses and enter its early assessment activity. The model estimates whether that course is likely to be passed or at risk of not being passed.

The course code identifies which course is being assessed; the prediction itself uses that course's completion, score and submission-timing values. Pass means the OULAD successful class (Pass/Distinction), while at risk includes historical Fail/Withdrawn outcomes.
